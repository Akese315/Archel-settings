**Deviation note (D-01 wording vs 0.8.4 reality, per RESEARCH Pitfall 3):** D-01 says "hyprpaper.conf write + hyprpaper reload" — hyprpaper 0.8.4 has no reload verb (`--help` lists only --config/--verbose/--version/--help) and its IPC socket is off (`ipc = off`, `hyprctl hyprpaper` fails rc=1 while the daemon runs). The one mechanism satisfying D-01's intent is: write the app-owned slice, `pkill -x hyprpaper`, respawn detached via the `setsid` argv shim. Same intent, one mechanism, no hyprctl-hyprpaper path.

**Deviation note (D-03/D-07 wording vs live reality):** D-03/D-07 say "live-applied via `hyprctl keyword`" — keyword is dead on Hyprland 0.56.2 (tracer deviation, already proven). Font live-apply uses `hyprctl eval 'hl.config({ misc = { font_family = ... } })'`.
</objective>
