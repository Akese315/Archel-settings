**As a** Hyprland user on Arch **I want to** change my window blur and transparency from `archel` **so that** I can restyle my desktop live without hand-editing configs.

Purpose: Phase-05 tracer. Prove the whole Hyprland integration architecture end-to-end on one path — CLI → core hyprland module → `hyprctl eval` live-apply → `getoption` read-back → app-owned snippet persistence (backup + atomic write + guarded require line) — before any breadth is added. Output: Working `archel appearance blur` and `archel appearance opacity` proven headlessly (fixtures + insta) and live-provable; the snippet writer is production-quality for all later plans.

**Deviation note (honors D-01..D-08 wording vs. live reality):** D-03/D-07 say "live-applied via `hyprctl keyword`" — `keyword` is dead on Hyprland 0.56.2 (returns "use eval", exits 0 doing nothing). The validated substitute is `hyprctl eval 'hl.config({ <category> = { <leaf> = <value> } })'` (live-verified 2026-10-07). Same intent, one mechanism.

**MVP Gate**: Task 1 is the runnable end-to-end slice (`archel appearance blur on` flips the live option and persists to the snippet); Task 2 only adds breadth (opacity) on the proven shape. Nothing downstream starts until Task 1's verify is green.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI args -> eval Lua string / snippet text | untrusted user values cross into compositor config syntax |
| app writer -> ~/.config/hypr/** | app code writes into the user's own config tree |
| hyprctl stdout -> parser | external compositor output crosses into display/JSON |

| T-05-02 | Tampering | snippet writer (D-08 breach) | high | mitigate | Write paths restricted to app-owned files + two guarded insertion lines; timestamped backup before EVERY write; tmp+rename atomicity; temp-dir write-scope spy test asserts no other path opened for writing |
| T-05-03 | Repudiation | unlogged config mutation | low | mitigate | Timestamped backup set (N=5 rotation) is the audit trail; FR ok-line names the exact key changed |
| T-05-04 | Information Disclosure | hyprctl stderr -> logs | low | accept | stderr log-only, no secrets exist in desktop-option scope; user-owned session |
