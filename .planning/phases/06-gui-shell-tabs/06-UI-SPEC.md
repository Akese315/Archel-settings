# Phase 6 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Stack reality:** Rust + CXX-Qt 0.10 + QML (Qt 6.11), QtQuick Controls **Fusion** style on-disk.
> No web design system exists (shadcn/tailwind not applicable — not a JS project). The design
> system here is the system Qt Quick Controls module + Fusion style. All visuals must be buildable
> with plain QtQuick/QtQuick.Controls/QtQuick.Layouts + QtQuick.Shapes or Canvas — no QtCharts
> (not installed), no design-tool artifacts, no unavailable modules.
>
> **Theme is system-followed, locked (D-24):** no in-app dark/light toggle. Every color below is
> expressed against the Fusion/SystemPalette roles, with literals allowed only where listed.
>
> **Language is French everywhere (Phase 1 D-06/D-07):** all user-facing strings French, diacritics
> live in `.qml`/catalog only, never in `.rs`.

## Typography

System-followed (D-24): declare sizes as **multipliers of the platform default font** with px
equivalents at 96 dpi (default ≈ 10pt/13px). Exactly 4 sizes, exactly 2 weights.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 1.0× ≈ 13px | regular (400) | 1.5 |
| Label | 0.85× ≈ 11px | regular (400) | 1.3 — field captions, units, secondary lines, log lines |
| Heading | 1.25× ≈ 16px | bold (700) | 1.2 — tab page title, GroupBox headers |
| Display | 1.6× ≈ 20px | bold (700) | 1.2 — Landing stat numbers, countdown seconds |

Rules: `font.pixelSize: Math.round(defaultFont.pixelSize * <ratio>)` where
`defaultFont = Qt.font({})`; never hardcode a family except `font.family: "monospace"` for the
StreamModal log view (D-13 "terminal-like" is achieved by monospace + palette.base background,
**not** by a hardcoded dark terminal theme — keeps D-24 system-follow intact).

## Color

Palette-relative (Fusion/SystemPalette roles; D-24 system-follow). Literal hex is permitted ONLY
for the three values marked ✱ below.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `SystemPalette.window` | Window and tab-page background |
| Secondary (30%) | `SystemPalette.base` / `SystemPalette.button` | Cards (GroupBox/Frame), rail, list rows, modals |
| Accent (10%) | `SystemPalette.highlight` | Reserved for: selected rail item, the single default/primary button of each modal, checked Switch/CheckBox/radio (Fusion default), focus ring, CPU graph line |
| Destructive | ✱ `#c01c28` | Package "Désinstaller" confirm button, keybind "Supprimer" confirm button — nothing else |
| Graph RAM line | ✱ `#2ec27e` | RAM sparkline stroke only (paired with legend chip) |
| Log foreground | `SystemPalette.text` on `SystemPalette.base` | StreamModal log view (monospace; no literal terminal colors) |

Accent reserved for: **only** the elements listed above — never all interactive elements.
Per-core expander lines (D-10): `SystemPalette.highlight` at 40% opacity (`Qt.alpha(0.4, …)`).
N/A token renders Body text at 40% opacity — honest, quiet, never red (N/A ≠ error).

## Layout & Screen Contracts

| Element | Contract |
|---------|----------|
| Window | Default 900×620 (D-23 spike size), minimum 720×480; geometry (x, y, w, h, maximized) restored from `~/.config/archel/window-geometry.json`, clamped/centered if off-screen (Pitfall 4); saved on close |
| Rail | Fixed width 200px; Column of 10 TabButtons, icon (16×16) beside French label, `spacing: 4`, item height 32px, checked item = Accent pill (proven pattern from Spike.qml, extended) |
| Content area | StackLayout fills remaining width; one file per tab in `qml/tabs/`; hidden tabs not rendered (D-03) but timers keep polling in the models |
| Tab page | Heading (tab name) + content Column/GridView, padding `lg` (16px); Landing = GNOME-Settings-like overview: update-count cards + system snapshot (D-22) |
| Sparkline | Canvas 100% width × 60px, rolling 60×1Hz samples (D-09), 2px polyline, CPU = accent, RAM = ✱ green, right-aligned current value label (CPU also shows clock speed, D-10); per-core expander reveals N 40%-alpha lines |
| Modal | `Dialog` with `modal: true`, `standardButtons` none (explicit buttons per copy contract), width 420px (StreamModal 560px, log height 240px) |
| Global modals | PairingModal lives at ApplicationWindow level — pops above any tab (D-21); ErrorModal likewise global (one error voice, D-17) |
| Disabled/scoped locking | During a long mutation only the acting tab's controls disable + BusyIndicator in its trigger button (D-15); other tabs fully usable |

## Interaction Contracts

- **Every write** opens ConfirmModal first (D-12) — no exceptions for toggles; pkexec note inside (D-18).
- **Confirm callbacks are core DI seams** (`apply_monitor_plan`, `pair_picked_with`, `apply_*_with`) — the modal *is* the confirm callback (RESEARCH Pattern 3); GUI never re-implements confirm/rollback logic.
- **Annuler in StreamModal** requests a stop (SIGINT path, core gap #1), never hard-kills (D-14).
- **Countdown**: 15 s ProgressBar; timeout auto-rolls-back (D-16).
- **BT scan**: burst on tab open or `Rechercher` press only (D-08); button disabled + BusyIndicator during the 12 s burst.
- **1 Hz tick**: QML `Timer` → `model.tick()`; in-flight flag skips stacked ticks; stale results dropped by sequence tag.
- **Keyboard**: Enter triggers the modal default button (DialogButtonBox roles); Esc = `Annuler`/`Fermer`.
